# Power BI guide: Women's Safety Incident Heatmap

This guide takes you from the app's data to a finished Power BI report in about 20-30 minutes.
You need **Power BI Desktop** (free, Windows): https://powerbi.microsoft.com/desktop

> Note: a `.pbix` file cannot be generated by the app, so you build the report once following these steps.
> The data, relationships, DAX measures and theme are all provided, which removes the hard parts.

## 1. Get the data (choose ONE option)

### Option A: CSV files (easiest)
1. In the app, log in as officer/admin, open **Analysis > Power BI data** (or `/powerbi`) and click **Download CSV package (.zip)**.
2. Unzip it. You get 5 CSV files plus this guide, `measures.dax` and `safety_theme.json`.
3. Power BI Desktop > **Home > Get data > Text/CSV**. Load each of the five files:
   `fact_incidents`, `dim_area`, `dim_type`, `dim_date`, `dim_hour`.
   (Tip: Get data > Folder loads them all at once.)

### Option B: Excel workbook
Download **Excel (.xlsx)** from the same page, then **Get data > Excel workbook** and tick all five sheets.

### Option C: Live from the database (refreshable)
Use `load_from_db.py` (see its header): **Get data > Python script**, paste the file, set `DB_PATH`,
tick the five tables. Click **Refresh** in Power BI to pull new incidents. Requires Python + pandas.

## 2. Check data types (Transform data)
- `fact_incidents[incident_date]` and `dim_date[date]`: **Date**
- `fact_incidents[incident_datetime]`: **Date/Time**
- `latitude`, `longitude`: **Decimal number**; set Data category to Latitude / Longitude (Column tools).
- Click **Close & Apply**.

## 3. Build the model (Model view)
Create these relationships (many-to-one, single direction, from the dimension to the fact):

| Fact column | Dimension column |
|---|---|
| `fact_incidents[area_id]` | `dim_area[area_id]` |
| `fact_incidents[type_id]` | `dim_type[type_id]` |
| `fact_incidents[incident_date]` | `dim_date[date]` |
| `fact_incidents[hour]` | `dim_hour[hour]` |

Then:
- Right-click `dim_date` > **Mark as date table** (date column = `date`).
- Select `dim_date[month_name]` > Column tools > **Sort by column** = `month_no`.
- Select `dim_date[weekday_name]` > Sort by column = `weekday_no`.
- Select `dim_hour[time_slot]` > Sort by column = `slot_order`.
- Always use fields from the **dim_** tables on axes and slicers.

## 4. Add the measures
Open `measures.dax`. Create an empty table (Home > Enter data, name `_Measures`), then for each block use
**Modeling > New measure** and paste it. This gives you Total Incidents, Severe, Open, Resolution Rate %,
Risk Score, Risk Level, Night/Weekend share, Peak Hour, Top Area, Last 30 vs Previous 30 days, Change %, MoM %.

## 5. Apply the theme
**View > Themes > Browse for themes** > select `safety_theme.json`.

## 6. Build the report pages

### Page 1: Overview
- **Cards**: Total Incidents, Severe Incidents, Open Cases, Resolution Rate %, Peak Hour Label, Top Area.
- **Slicers**: `dim_area[area_name]`, `dim_type[type_name]`, `dim_date[date]` (Between), `fact_incidents[status]`, `dim_hour[time_slot]`.
- **Clustered bar**: Y = `dim_area[area_name]`, X = Total Incidents (sort descending).
- **Column chart**: X = `dim_hour[hour_label]`, Y = Total Incidents.
- **Donut**: Legend = `dim_hour[time_slot]`, Values = Total Incidents.
- **Column chart**: X = `dim_date[weekday_name]`, Y = Total Incidents.
- **Bar chart**: Y = `dim_type[type_name]`, X = Total Incidents.
- **Line chart**: X = `dim_date[year_month]`, Y = Total Incidents.

### Page 2: Hotspot map
- **Map** (bubble): Latitude = `fact_incidents[latitude]`, Longitude = `fact_incidents[longitude]`, Size = Total Incidents.
  For a true heat layer use the **Azure Maps** visual (Format > Layers > Heat map).
- Add a **table**: `dim_area[area_name]`, Total Incidents, Risk Score, Risk Level, Resolution Rate %.
  Format > Cell elements > Background color > Field value > `Risk Color`.

### Page 3: When does it happen?
- **Matrix**: Rows = `dim_area[area_name]`, Columns = `dim_hour[hour]`, Values = Total Incidents.
  Cell elements > Background color > Gradient (minimum light blue, maximum red). This is the area-by-hour heat grid.
- **Stacked bar**: Axis = `dim_type[type_name]`, Legend = `dim_hour[time_slot]`, Values = Total Incidents.

### Page 4: Trend and actions
- **Cards**: Incidents Last 30 Days, Incidents Previous 30 Days, Change %.
- **Clustered column**: Axis = `dim_area[area_name]`, Values = Incidents Last 30 Days and Incidents Previous 30 Days.
- **Text box** with your recommended actions (patrol, lighting, awareness, close open cases).

### Interactivity (the Power BI way)
Clicking any bar or slice cross-filters every other visual. Use **Edit interactions** to control it,
**Drill through** on `dim_area[area_name]` for an area detail page, and **Bookmarks** for saved views.

## 7. Share and refresh
- **Home > Publish** to the Power BI service (needs a Power BI account) and pin visuals to a dashboard.
- CSV/Excel data does not refresh itself: download a new package from the app and replace the files,
  or use Option C with a gateway for scheduled refresh.

## 8. Privacy
The export contains **no names, emails or user IDs**, only incident time, area, type, severity, status and
location. The data is still sensitive: share the report only with people who need it, and follow your local privacy rules.

## Tables in the export

| Table | Purpose |
|---|---|
| `fact_incidents` | one row per incident: date, datetime, hour, time_slot, weekday_no, area_id, type_id, severity, status, is_open, is_severe, latitude, longitude |
| `dim_area` | area_id, area_name, city, latitude, longitude |
| `dim_type` | type_id, type_name, severity |
| `dim_date` | one row per day: year, month, weekday, is_weekend |
| `dim_hour` | hour 0-23, label, time_slot, slot_order |
