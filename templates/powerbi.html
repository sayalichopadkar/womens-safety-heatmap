Quick steps

  1. Download the CSV package and unzip it.
  2. Power BI Desktop → Get data → Text/CSV, load the 5 CSV files.
  3. Create relationships: fact_incidents to dim_area (area_id), dim_type (type_id), dim_date (incident_date = date) and dim_hour (hour).
  4. Paste the measures from measures.dax and apply the theme.
  5. Add the visuals listed in the guide (cards, slicers, bar/column/donut/line charts, map, heat-grid matrix).
